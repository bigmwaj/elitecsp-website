# Elite CSP Documentation Index

This directory contains enterprise documentation for the full repository (`ui-app` + `api-app-project`).

## Structure

- `architecture/` — system architecture, dependency map, and interaction flows
- `api/` — OpenAPI-style endpoint documentation and integration notes
- `aws/` — infrastructure and IAM/security design notes
- `deployment/` — CI/CD, production deployment, rollback, and release guidance
- `troubleshooting/` — common failure patterns and remediation steps
- `user-guides/` — end-user guides (contact, job application, navigation)
- `developer-guides/` — onboarding, module guides, quality/testing/refactoring guidance
- `diagrams/` — textual architecture and deployment diagrams
- `runbooks/` — operational and rollback runbooks
- `reports/` — repository analysis, security, technical debt, and remediation plan

## Recommended Reading Order

1. `reports/repository-analysis-summary.md`
2. `architecture/system-overview.md`
3. `api/openapi-style.md`
4. `deployment/ci-cd-reference.md`
5. `reports/prioritized-remediation-plan.md`
