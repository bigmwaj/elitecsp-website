# User Guide: Job Application Flow

## How to apply

1. Open Careers page.
2. Choose a job and click Apply.
3. Fill applicant details and cover letter.
4. Upload CV (`.pdf` or `.docx`, max 5 MB).
5. Submit application.

## What to expect

- On success: application confirmation state appears.
- CV type/size validation errors are shown when applicable.

## Troubleshooting

- Ensure CV is PDF or DOCX.
- Ensure file size is under 5 MB.
- Retry if submission fails; verify required fields.
